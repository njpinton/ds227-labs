# DS 227 &mdash; Lab Notebooks

Knowledge Discovery in Data &middot; Department of Computer Science, University of the Philippines Cebu

Turning raw, messy data into knowledge that survives scrutiny.

## How to use these

Click **Open in Colab** for the week you are on. Colab opens the notebook read-only from
this repository &mdash; use **File &rarr; Save a copy in Drive** before you start working,
or your changes will be lost when the tab closes.

You do not need to install anything. Everything runs in the browser.

## Submitting

1. **File &rarr; Download &rarr; Download .ipynb**
2. Open `https://portal.latarak.com/course/ds227/lab/<week>/submit`
3. Sign in with your student number and upload the file.

Re-uploading replaces your previous attempt; the most recent version is the one kept.
Your instructor issues your first password, which you change on first sign-in.
